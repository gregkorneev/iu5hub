# Roadmap

| Priority | Milestone | Exit criterion |
| --- | --- | --- |
| P0 | Foundation | Vite/React/TS, Wiki, lint/typecheck/test/build, CI |
| P0 | Telegram-only migration | устаревшие Web/Beget решения удалены или помечены superseded; Telegram integration и materials boundaries реализованы и проверены |
| P0 | Hosting | `dist/` публикуется на Cloud.ru Evolution Object Storage по HTTPS; Bot открывает Mini App |
| P1 | Catalog | семестры, предметы, карточки материала, поиск, deep links |
| P1 | Quality | responsive, accessibility, adversarial smoke checks |
| P1 | Release | Cloud.ru guide, SPA fallback/routing strategy, production build, Telegram smoke test |
| P2 | Polish | performance, UX, empty/error content refinement |
| P3 | Integration | sync Яндекс.Диска, backend, accounts, favorites, MAX/PWA при доказанной потребности |

Работу каждого этапа завершать проверками, обновлением Wiki, атомарным commit и push.
