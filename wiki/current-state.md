- **Tag-based folder search:** production search uses only the curated «Теги» and «Преподаватель» values from the 29-folder Excel queue, via compact `src/generated/search-folder-index.json`. Suggestions update while typing and open the matched folder directly; suggestions and result cards show the folder's parent path beneath its name to distinguish duplicate names. - **Deployment policy:** `deploy-cloudru` и `deploy-cloudflare-pages` запускаются только после `verify`, только для push в `main` и только при соответствующем literal enable variable; оба публикуют только статический Mini App. Cloud.ru job генерирует `error.html`, cache-ит hashed `assets/` как immutable, sync-ит остальные root files с no-cache и публикует `index.html` последним с no-store. Технический host URL не распространяется студентам; Bot/Mini App URL остаётся пользовательским входом.
- **Local Telegram development:** для временного ручного теста использовать `npm run dev:telegram` и `@iu5_archive_bot` только как designated dev-test bot. URL Quick Tunnel меняется с каждым запуском, не хранится в Git и не подтверждает настройку бота, пока реальный запуск не проверен.
