У всех карточек файлов фиксированная правая колонка скачивания: короткое и длинное название не могут сдвинуть кнопку, а Playwright измеряет симметрию на desktop и mobile во всех browser engines. Ранее устранены критическая ARIA-ошибка search suggestions, отсутствие `h1` на главной, race при быстром переходе между папками, stale download error после перехода в другой каталог и clipping подсказки поиска под каталогом на iPhone. Шапка теперь имеет свой слой: hero больше не перехватывает касание ссылки «Статистика» администратора на главной. Playwright проверяет переход на защищённый dashboard в Chromium, mobile Chromium и WebKit. Поиск по живому Яндекс.Диску имеет общий 10-секундный дедлайн, поэтому зависший обход показывает ошибку вместо вечного loader и сначала углубляется в совпавшую папку, чтобы вернуть подходящий вложенный файл (включая УТП). Подсказки также сопоставляют латинскую транслитерацию с кириллическими именами: `Ma` находит `Математический анализ`. Все три курса подключены к публичным папкам; для третьего share root `BMSTU` сочетается с вложенным путём `IU5/3 course`.
- **Deployment policy:** `deploy-cloudru` и `deploy-cloudflare-pages` запускаются только после `verify`, только для push в `main` и только при соответствующем literal enable variable; оба публикуют только статический Mini App. Cloud.ru job генерирует `error.html`, cache-ит hashed `assets/` как immutable, sync-ит остальные root files с no-cache и публикует `index.html` последним с no-store. Технический host URL не распространяется студентам; Bot/Mini App URL остаётся пользовательским входом.
- **Local Telegram development:** для временного ручного теста использовать `npm run dev:telegram` и `@iu5_archive_bot` только как designated dev-test bot. URL Quick Tunnel меняется с каждым запуском, не хранится в Git и не подтверждает настройку бота, пока реальный запуск не проверен.
