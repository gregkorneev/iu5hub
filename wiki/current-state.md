- **Current UI guard:** на mobile длинный заголовок плитки семестра использует полную ширину после отдельной строки значка. Даже `Парадигмы и конструкции языков программирования` остаётся внутри границ и переносится только по пробелам; файл в той же папке занимает всю строку с фиксированной кнопкой скачивания. Playwright измеряет `scrollWidth` заголовков и геометрию карточки на 320 и 390 px.
- **Last UI QA change:** 2026-09-21 — весь UI переведён на локальную гарнитуру ALS Sector: Regular для текста, Bold для жирных начертаний, Stencil зарегистрирован как доступный вариант. Playwright ожидает загрузку Regular и Bold. Все папки семестров в `sem`/`семестр`, независимо от регистра, используют единую сетку из двух плиток на mobile. Заголовки папок переносятся только по пробелам: общее правило больше не разрывает слово в середине. Playwright проверяет русское имя папки семестра, колонки и computed word wrapping. Единый публичный asset `/logo-iu5.jpeg` заменён на предоставленный знак «5», поэтому новая иконка отображается в шапке всех маршрутов; Playwright проверяет его успешную загрузку. На главной portrait остаётся фиксированным в фактическом Telegram viewport без прокрутки по обеим осям, а landscape разрешает вертикально пролистать не поместившийся контент и по-прежнему блокирует горизонтальную прокрутку. Playwright проверяет оба режима. У всех карточек файлов фиксированная правая колонка скачивания: короткое и длинное название не могут сдвинуть кнопку, а Playwright измеряет симметрию на desktop и mobile во всех browser engines. Ранее устранены критическая ARIA-ошибка search suggestions, отсутствие `h1` на главной, race при быстром переходе между папками, stale download error после перехода в другой каталог и clipping подсказки поиска под каталогом на iPhone. Шапка теперь имеет свой слой: hero больше не перехватывает касание ссылки «Статистика» администратора на главной. Playwright проверяет переход на защищённый dashboard в Chromium, mobile Chromium и WebKit. Поиск по живому Яндекс.Диску имеет общий 10-секундный дедлайн, поэтому зависший обход показывает ошибку вместо вечного loader и сначала углубляется в совпавшую папку, чтобы вернуть подходящий вложенный файл (включая УТП). Подсказки также сопоставляют латинскую транслитерацию с кириллическими именами: `Ma` находит `Математический анализ`. Public course 1 and 2 are connected; course 3 intentionally has no URL.
- **Deployment policy:** `deploy-cloudru` и `deploy-cloudflare-pages` запускаются только после `verify`, только для push в `main` и только при соответствующем literal enable variable; оба публикуют только статический Mini App. Cloud.ru job генерирует `error.html`, cache-ит hashed `assets/` как immutable, sync-ит остальные root files с no-cache и публикует `index.html` последним с no-store. Технический host URL не распространяется студентам; Bot/Mini App URL остаётся пользовательским входом.
- **Local Telegram development:** для временного ручного теста использовать `npm run dev:telegram` и `@iu5_archive_bot` только как designated dev-test bot. URL Quick Tunnel меняется с каждым запуском, не хранится в Git и не подтверждает настройку бота, пока реальный запуск не проверен.
