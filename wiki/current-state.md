# Current state

- **Project status:** Telegram-only MVP мигрирован и validated locally. CI verification и выключенный по умолчанию Cloud.ru deploy job уже в Git; Environment `cloudru-production` создан с `CLOUDRU_DEPLOY_ENABLED=false`. Внешний production release ожидает реальные Cloud.ru/Telegram/Yandex Disk настройки и smoke test.
- **Current milestone:** Telegram Mini App: каталог материалов, Cloud.ru Evolution Object Storage deployment и реальный каталог Яндекс.Диска.
- **Completed:** React/Vite SPA, routing, статический `MaterialsRepository`, responsive UI, CI, unit tests и локальный browser smoke test. Эти результаты требуют адаптации к новой Telegram-only границе, а не считаются production validation в Telegram.
- **In progress:** provisioning Cloud.ru и staging first deployment; настройка BotFather Mini App URL и реального каталога Яндекс.Диска.
- **Next:** создать HTTPS static-website endpoint с index/error documents в Cloud.ru; ограничить service account только production bucket/prefix; заполнить Environment secrets `CLOUDRU_ACCESS_KEY_ID`, `CLOUDRU_SECRET_ACCESS_KEY`, `CLOUDRU_BUCKET` и optional `CLOUDRU_PREFIX`; включить `CLOUDRU_DEPLOY_ENABLED=true`; заменить demo-ссылки реальным каталогом Яндекс.Диска; задать URL Mini App в BotFather/боте.
- **Known blockers:** Environment уже создан, но deploy намеренно не запустится при `CLOUDRU_DEPLOY_ENABLED=false` и без Cloud.ru endpoint/least-privilege secrets. Также отсутствуют Telegram bot access и реальный каталог Яндекс.Диска. Ни один secret не должен попадать в Git или frontend bundle.
- **Important architecture facts:** один статически собираемый React/TypeScript/Vite frontend существует только внутри Telegram Mini App; UI зависит от `MaterialsRepository` и централизованного Telegram integration layer; Cloud.ru — заменяемый technical host; тяжёлые файлы остаются на Яндекс.Диске.
- **Team workflow:** постоянная небольшая команда; новые роли создаются только для действительно новой специализации, а обычные задачи направляются существующим агентам.
- **Last significant change:** 2026-09-11 — принята целевая Telegram-only архитектура: Telegram Bot является постоянной публичной точкой входа, Cloud.ru Evolution Object Storage — только техническим hosting, Яндекс.Диск — файловым хранилищем (ADR-0003). Документация старого Beget/Web решения помечена superseded.
- **Deployment policy:** `deploy-cloudru` запускается только после `verify`, только для push в `main` и только при `vars.CLOUDRU_DEPLOY_ENABLED == 'true'`; он генерирует `error.html`, cache-ит hashed `assets/` как immutable, sync-ит остальные root files с no-cache и публикует `index.html` последним с no-store. Технический Cloud.ru URL не распространяется студентам; Bot/Mini App URL остаётся пользовательским входом.
