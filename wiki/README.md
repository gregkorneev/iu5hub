# Student Hub Wiki

Долговременная память проекта Student Hub — Telegram-first и Telegram-only приложения для поиска учебных материалов и перехода к ним на Яндекс.Диске. Единственная пользовательская точка входа — Student Hub Bot, который открывает Telegram Mini App.

**Этап:** миграция MVP на принятую Telegram-only архитектуру. Перед существенной работой прочитайте `current-state.md`, затем профильный раздел и актуальные ADR.
