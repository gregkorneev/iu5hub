# Студент ИУ5 Wiki

Долговременная память проекта Студент ИУ5 — Telegram-first и Telegram-only приложения для поиска учебных материалов и перехода к ним на Яндекс.Диске. Единственная пользовательская точка входа — бот «Студент ИУ5», который открывает Telegram Mini App.

**Этап:** миграция MVP на принятую Telegram-only архитектуру. Перед существенной работой прочитайте `current-state.md`, затем профильный раздел и актуальные ADR.
