# Requirements

## Product goal

Студент за минимальное число действий находит предмет и материал, затем открывает его на Яндекс.Диске.

## MVP (P0/P1)

- Главная: название, семестры, предметы, быстрый поиск, новые материалы.
- Маршруты: `/`, `/semester/:semester`, `/subject/:slug`, `/subject/:slug/:category`, `/material/:id`, `/search?q=`.
- Материал: название, предмет, категория, описание (если есть), внешняя ссылка.
- Поиск по названию, предмету, категории и ключевым словам; при вводе показываются до пяти ранжированных подсказок с прямым переходом к материалу или предмету.
- Responsive/mobile-first, доступная keyboard-навигация, видимые focus states, понятные empty/error states.
- Единственный пользовательский интерфейс — Telegram Mini App, открываемый из бота «Студент ИУ5». Отдельный публичный Web-сайт и экран выбора Web/Telegram не входят в продукт.
- Telegram-особенности скрыты за централизованным integration layer; UI не зависит от глобального API или hosting URL.

## Constraints

Материалы тяжёлых форматов не хранятся в приложении. До backend Telegram initData применяется только для UI-персонализации и не считается удостоверением личности.
