# Студент ИУ5

Telegram Mini App для студентов кафедры ИУ5: каталог учебных материалов, поиск по предметам и преподавателям, расписание и личный профиль с избранным. Файлы хранятся на Яндекс Диске, а приложение помогает быстро найти нужную папку или материал.

**Production Mini App:** [iu5hub.pages.dev](https://iu5hub.pages.dev) · Пользовательский вход — Telegram-бот «Студент ИУ5».

Приложение рассчитано на запуск из Telegram. Веб-адрес используется как технический адрес Mini App; каталог и поиск также доступны в обычном браузере для локальной разработки.

## Возможности

- Каталог курсов, семестров, папок и файлов на Яндекс Диске.
- Поиск учебных материалов по предмету или преподавателю.
- Расписание учебных групп ИУ5.
- Профиль с избранными папками и материалами.
- Telegram-тема, навигация и безопасные отступы Mini App.

## Локальный запуск

Нужен Node.js 22 и npm.

```bash
npm ci
npm run dev
```

Vite выведет адрес локального приложения. Для локального тестирования Mini App через Telegram WebView используйте отдельную команду:

```bash
npm run dev:telegram
```

Она открывает временный Quick Tunnel к локальному серверу разработки. Адрес туннеля меняется при каждом запуске; подробности — в [инструкции по локальной разработке с Telegram](wiki/local-telegram-development.md).

## Основные команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить Vite в режиме разработки |
| `npm run dev:telegram` | Запустить локальную разработку с Quick Tunnel для Telegram |
| `npm run build` | Собрать приложение в `dist/` |
| `npm run lint` | Проверить стиль и ошибки ESLint |
| `npm run typecheck` | Проверить типы TypeScript |
| `npm test` | Запустить модульные и Node.js тесты |
| `npm run test:ui` | Запустить браузерные проверки Playwright |
| `npm run qa` | Выполнить полный локальный набор проверок и сборку |

Перед отправкой изменений обычно достаточно выполнить `npm run qa`.

## Данные и настройки

Каталог и индекс поиска собираются из данных репозитория. Расписание публикуется как статические JSON-файлы. Скрипты синхронизации и проверки описаны в `package.json`; структура данных и порядок обновления — в [Wiki проекта](wiki/README.md).

Скопируйте `.env.example` в `.env`, если нужна локальная настройка публичного адреса Worker для аналитики. Для базового запуска приложения секреты и заполненный `.env` не требуются. Значения `VITE_*` включаются в публичную сборку — не помещайте туда токены бота, пароли или другие секреты.

## Публикация

Production Mini App размещён на Cloudflare Pages. Основной путь публикации — push в `main`, после которого настроенная интеграция Pages запускает сборку. Проект также содержит отключённые по умолчанию GitHub Actions для проверки и дополнительных вариантов деплоя. Подробные инструкции и требования к конфигурации находятся в [Wiki: публикация](wiki/deployment.md).
